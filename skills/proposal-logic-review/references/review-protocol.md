# 审查协议：问题能否禁得住追问

## 1. 审查目的

诊断“主张是否被论证、方法是否回答问题、验证是否兑现主张”，不是展示评审者知道更多技术。

优先判断最早断裂的关键链条。不要在研究目标尚未确定时纠缠某个 loss 的名称，也不要因后半部分尚未完成实验，就要求 proposal 提供已完成论文级的结果。

## 2. 严格区分四种结论

| 判断 | 含义 | 正确处理 |
|---|---|---|
| 逻辑断裂 | 给出的前提即使成立，也推不出后续结论 | 指出缺失桥梁或目标偷换，要求缩小／修改主张 |
| 稿件缺证据 | 正文没有为某个事实或局限提供足够依据 | 指定需要何种来源；不能直接认定该说法为假 |
| 待实验验证 | 合理的科学假设，尚待方法和对照检验 | 检查可检验性，不以没有结果为由否定 |
| 表达可改 | 核心逻辑成立，但重复、拗口或信息位置不当 | 最小编辑，不重开整个课题 |

审查等级可用“阻断主线／重要／表达”，不要凭空给出精确录取概率、论文接收概率或具有权威意味的总分。

## 3. 先复述，不替作者补洞

只根据正文，写一句：

> 作者要在[条件]下改善[终点]，提出[尚未确立的关系]，打算通过[方法及对照]验证。

无法填写的部分标记“稿件未说明”。另列作者补充材料支持的解释，不能把它悄悄归入正文。没有真实隔离工具时，不声称已进行空白上下文子 agent 评审。

## 4. 沿七个位置拷问

### A. 目标是否足够具体

追问：究竟产出什么、服务什么任务、以什么质量与代价评价？“建设数字孪生”“改善具身智能”只是背景还是本期可实现目标？

检查：长期愿景是否压在六个月成果上；新视角渲染是否被偷换为定位准确率；资产可编辑是否被偷换为真实物理参数正确。

### B. 技术为什么被选择

追问：为何这项技术适合所需输出和研究变量？存在更简单、成本更低或无需该中间表示的路线吗？

检查：不要把任务与表示作假二选一。以 SLAM 与 3DGS 的讨论为例，先确认它们在稿件中各是什么，不要仅凭词名判替代关系。方法范围内的改进不自动承担全面替代其他路线的证明责任。

### C. 现有工作究竟支持什么

追问：研究已经改善规模、质量或时间中的哪一项？输入、条件与评价和本项目是否相同？

检查：
- 模型更紧凑不直接证明总流程更快。
- 特定设置中质量提高不直接证明所有质量约束保持。
- SfM 初始化与 LiDAR 输入不能未加说明地互换。
- 一篇论文某个参数敏感，不等于整个领域都不考虑配置。

涉及具体论文时，用户材料是来源快照，不是重新核实过的完整文献结论。

### D. 为什么从局限走到这个问题

追问：缺少的是一个工具、一个未试过的组合，还是一项会影响实际结果的判断依据？若获得这个答案，会改变什么决定？

反例：“所有人分别做 A、B、C，所以我联合做”只说明组织差别。要补“何种相互作用使独立配置可能失效，以及如何检验联合处理值得增加开销”。

### E. 为什么方法能够回答它

追问：每项方法控制哪个因素、观察哪个响应、排除哪种竞争解释？

用表格对应：科学问题 → 变量／关系 → 方法操作 → 产出 → 对照 → 判据。若问题研究必要观测，但所有实验输入完全不变，就存在覆盖不足；固定输入实验可能有效，但只能支持较窄的初始化问题。

“搭数据集”只有在它使必要因素可控制、真值可获得或评测可重复时，才支持机制研究。做曲线后仍按任意规则配置，也没有完成机制到方法的连接。

### F. 成功标准是否偷换

追问：实验最终赢的指标，是否就是引出研究问题时要改善的指标？

本轮讨论中的典型反例：以“逐领域分割训练低效”作为动机，却用更大训练资源训练全模态系统，未改善所声称的效率或质量。此时不能改口用“更通用”代替原目标，除非作者明确重定目标并补适合的对照。

同理：
- 固定迭代下质量更高，只能部分说明学习效果，不直接证明总耗时降低。
- 参数少、学习率低或数据少，不等于实际执行的工作减少。
- 多模块完整方案优于基线，不证明所解释的机制唯一成立。

### G. 结论允许推多远

追问：在哪些新条件上验证？是否存在失败或负收益条件？研究结果支持的是方法、经验规律、适用范围还是普遍定理？

不能把“拟研究关系”写成“必然揭示本质”；也不能因为没有普适理论，就否认严谨经验研究的价值。结论应当与证据范围一致。

## 5. 研究机制时的专门检查

对于机制驱动的算法计划，至少要说明：

1. 条件和变量是什么；哪些可以独立改变。
2. 观测响应是什么；不同原因能否产生相似现象。
3. 哪些干预可区分竞争解释。
4. 得到的关系是否预测新条件，而非只解释已看结果。
5. 关系如何形成操作规则；规则相比简单替代是否值得。

独立控制、匹配初始状态、部分延长训练对照、多条件测试都是候选手段，不是统一强制实验清单。需要根据主张选择最小充分对照。

## 6. 效率与验证口径

若声称质量保持的加速，核心是：

`同一预先约定质量约束 + 可比资源/输入条件 → 更低总处理和训练成本`

同时可报告固定成本质量曲线。检查预处理、规则拟合、图像特征、I/O、训练与额外试配是否遗漏；可复用成本应披露其复用范围，不能无条件摊销为零。

不要盲目要求所有对照固定最终参数量：研究采样、形状、调度或总方法时，匹配变量不同。必须指出每个比较能回答什么、不能回答什么。

不要让测试数据参与观测选择、规则拟合、容量搜索或 checkpoint 选择。训练所用 LiDAR 可以作为输入一致性参照，但不因此成为独立精度真值。生成的观测也不能被当作新获取的真实信息。

## 7. 逐轮拷问的节奏

每轮只处理最有决定性的一项：

> 你目前把[现象]归因于[解释]；假如它实际来自[替代解释]，你的方法还会有效吗？现有材料或哪一个对照能区分二者？

用户回答后，做三件事：确认被支持的部分，指出仍缺的一步，给出可直接写入的连接句。不要将用户尚未选择的答案写成已确认决策。

若材料已给出答案，就引用并解释，不用追问演示严格性。若逻辑成立，应明确通过，不能无穷扩展研究范围。

## 8. 完整审查报告的最小单元

每个问题记录：

- 原文位置与短引文。
- 问题类型与影响等级。
- 断裂的推导或不受支持的事实。
- 为什么会影响研究主张，而非只是表达偏好。
- 所需证据或关键对照。
- 最小修订／一个关键追问。

默认最多展开三个核心问题，其余归为待核验项。可以给出“保持目标但换方法”与“保留方法但缩小问题”两条修复路径，但不能悄悄替作者选择。

## 9. 审查完成条件

完成不等于保证实验成功。以下成立即可进入写作：研究目标可界定；证据、假设和方案分开；主要方法对应问题；验证能够支持或削弱目标主张；尚未确定的部分被如实保留。

纯行文问题不用升级成重新调研，未经验证的合理假设不用包装成必然结论。审查要严在逻辑和证据，不严在表演性的否定。
