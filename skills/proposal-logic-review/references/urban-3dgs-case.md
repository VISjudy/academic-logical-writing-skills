# 已确认案例：用三维重建 proposal 学习论证，而不是记住技术清单

## 0. 依据与边界

依据用户最终确认的 `Hongsheng_Huang_Proposal_2027_Updated_CN.docx` 与对应英文版，不以更早的长版、Ready版或初始化执行计划替换本次写作基准。原文节选见 [approved-excerpts.md](../examples/approved-excerpts.md)，出处记录见 [source-ledger.md](source-ledger.md)。

下文“原句”来自确认稿；“解读、模板、反例与修复”是从本次写作过程提炼的方法，不是论文实验已经验证的结论。参考文献描述是确认稿中的来源快照，本次未重新核验外部原文或更新发表状态。

本案例选择静态街道的激光—视觉三维高斯重建作为主题。复用 skill 时不强迫其他项目采用这些对象、术语、两问三方法或计算资源。

## 1. 这一稿的写作目标

用两页让评审看懂：为何这个研究值得做、现有进展之后还有哪项判断需要依据、候选方法为什么可能回答问题，以及怎样检验这项回答是否有用。

写作顺序不是“拥有 LiDAR 和 Blender → 寻找机器人应用”，而是“城市三维底座的质量与规模要求 → 质量保持的重建效率 → 哪些投入必要 → 如何减少无谓优化”。

正文中的工具和应用各有位置：

| 内容 | 在论证中的身份 | 不应升级为 |
|---|---|---|
| 城市数字孪生 | 研究价值与输出要求 | 本期已经完成全城部署 |
| 已配准 LiDAR 与多视图影像 | 已有输入条件 | 重新解决定位与采集的独立任务 |
| 3DGS | 适合所需输出的研究对象 | 城市重建唯一技术 |
| VLM＋Blender | 构建受控实验条件的工具 | 自动构成方法创新或真实世界完整真值 |
| 表面级配置规则 | 从观测关系到算法的关键产出 | 只画响应曲线就已完成决策机制 |
| 初始化与状态调度 | 减少实现该配置的优化成本 | 因分阶段名称不同就认定新颖 |
| 机器人 demo | 原型探索与潜在用途 | 独立证明策略性能、精确物理或普适泛化 |

## 2. 第一页的四处重要写法

### 2.1 先提出成果要求，再说明效率为什么重要

原句：

> 城市数字孪生需要兼顾几何精度与新视角外观真实感的三维底座，以支持空间量测与实景呈现。

接下来才写规模化的时间与资源压力，并落到已有配准数据下的数据处理和优化效率。段落承担“研究什么以及为什么”，不在首段解释 SH、相机分辨率或损失。

通用原则：应用必须提供质量与终点的理由，不能只是贴在技术路线前面的背景词。

### 2.2 承认三类进展，但不把三类虚构成同一系统

确认稿分为：大场景规模；几何引导的表示与质量；训练成本与加速。每一类引用不同方法支持相应进展。

通用原则：分类说明每类解决什么，而不是强行宣称“第二类建立在第一类分块框架内”。对论文输入和实验口径不同之处保持区分。

### 2.3 用综合局限引出具体决策

原句：

> 现有研究已从大场景组织、几何引导和训练加速三个层面改善质量与效率，但仍需建立随局部表面与观测条件变化的协同配置依据。在给定质量要求下，如何联系输入选择、高斯容量和参数更新，判断哪些配置必要、哪些投入收益有限，仍需进一步研究。

通用原则：先承认“配置策略有效”，再聚焦“面对不同条件，判断何种配置足够的依据”。不是宣称已有工作全部无效，也不是把单篇论文的参数问题当作整个领域的证明。

注意：这仍是 proposal 的研究定位。未来主张“尚无任何联合配置研究”时，必须另行做对应文献核验；本 skill 不提供这种保证。

### 2.4 科学问题采用“专业关系＋直白问题”

原句标题：

> 有效观测与局部高斯表征的匹配规律：达到目标质量，需要哪些输入与高斯配置？
>
> 几何—外观先验对初始化与收敛的作用机制：怎样利用已有信息，减少达到目标质量所需的优化？

连接句：

> 第一问确定足够的观测与表示配置，第二问研究如何以更低成本实现该表示。

通用原则：标题让同行知道研究对象，问句让读者立刻理解未知是什么；问题之间要有输出与输入的连接，不是两个不相关任务。

## 3. 第二页的方法为什么能够对应第一页

确认稿的方法开口原句：

> 第一项让影响因素能够被区分；第二项回答“需要怎样的输入与表示”；第三项回答“怎样利用先验减少实现该表示的优化成本”。

| 方法 | 对应问题 | 必须产出什么 | 不能只做到什么 |
|---|---|---|---|
| 可控仿真与观测实验 | 为区分信息、表示和收敛限制提供条件 | 同场景下可重复的因素变化与质量—成本观测 | 场景很逼真、数据量很大 |
| 表面级评价与联合配置 | 第一问：哪些输入与表示足够 | 条件化响应模型和能够用于新场景的配置规则 | 每个场景重新试出一组最好参数 |
| 先验初始化与状态优化 | 第二问：如何以更低成本实现 | 合适初值及有依据的参数更新决策 | 仅给训练划分阶段或增加新 loss |

方法二是本案例的中心，因为它把实验所识别的关系变成输入选择与表示决定。机制研究若没有这一桥梁，仿真数据和训练策略仍可能是互不关联的两项工程。

## 4. 从历史修改中得到的反例

以下是为教学压缩的失败写法，不是当前确认稿的逐字错误，也不是对相关领域的独立事实断言。

| 容易出现的写法 | 逻辑问题 | 更合适的修复方向 |
|---|---|---|
| “城市级重建做不了，所以提出我们的3DGS。” | 把目标重要当成现有技术失败的证据 | 承认已有规模方法，限定质量保持条件下的具体成本问题 |
| “既然机器人要建图，就必须使用3DGS。” | 从应用跳到唯一技术，忽略层次与替代 | 说明目标输出与显式表示的研究价值，不宣称唯一性 |
| “此前没有统一 A、B、C，因此联合必定更好。” | 文献组织空白不等于有益机制 | 提出何种交互会使独立规则失效，并与独立调优组合比较 |
| “生成逼真场景，说明观测—容量机制成立。” | 工具可用不等于研究问题已回答 | 说明场景允许什么独立干预，以及怎样获得规则 |
| “减少高斯，所以实现了加速。” | 数量是代理，不是目标终点 | 比较达到同一质量的总处理和训练成本 |
| “固定输入、固定数量的纹理消融证明必要观测规律。” | 实验没有改变所声称研究的变量 | 固定数量实验支持初始化收益，必要观测另做独立控制 |
| “局部演示证明前馈网络和机器人性能提升。” | 从环境产物跳到下游结论 | 将这些写为应用潜力，实测下游收益需对应实验 |

## 5. 质量—成本的承诺怎样保持不变

当前确认稿第一问、第二问及访问安排共享的终点，是保持几何与新视角质量下的效率。不要让最终结果变成更昂贵的模型只获得更高画质。

可用于审查的例子：如果特征监督降低训练步数，却让每步成本增大，应看总时间；如果额外几何分析抵消优化节省，应报告其权衡；如果减少数量却损害关键区域质量，应按预先约定要求评价，不能只挑总体均值。

这些检查属于对研究主张的验收，不要求全部用长段落加入正式正文。确认稿将独立视角、参考几何及相同质量／资源比较放在方法和访问安排中。

## 7. 一句通用结论

**不是先挑技术再包装问题，而是先说清楚哪个判断尚缺依据，再设计能产生依据、形成决策并接受验证的方法。**

研究能力在这里体现为：既能解释为什么值得做，也能说明什么情况下自己的解释或方法不成立。
